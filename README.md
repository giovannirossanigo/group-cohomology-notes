# Group cohomology

Lecture notes for Kevin Li's course on group cohomology at the University of Regensburg, winter semester 2023–2024, transcribed and edited by Giovanni Rossanigo.

- [Read the notes (PDF)](main.pdf)
- [LaTeX source](main.tex)

The notes cover group cohomology from a geometric point of view, including classifying spaces, resolutions, cohomological and geometric dimension, and finiteness properties.

The transcription includes corrections, added explanations, and later references; editorial changes are recorded in comments in the LaTeX source.
The commutative diagrams include editable [quiver](https://q.uiver.app) links.

To compile the notes with a TeX Live or MiKTeX installation that includes `latexmk`, run:

```sh
latexmk -xelatex main.tex
```
